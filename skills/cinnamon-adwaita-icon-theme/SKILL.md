# adwaita-icon-theme Skill

This skill provides information about the Adwaita icon theme, which is the default icon theme for the GNOME desktop environment and Cinnamon desktops on Linux.

**Overview:**
- Adwaita is the default graphical icon theme for GNOME and Cinnamon desktops
- Provides a consistent visual language across applications
- Part of the gnome-icon-theme package

**Usage:**
- The theme is automatically used by GNOME and Cinnamon desktops
- Icons are organized in standard hicolor theme directories
- Can be used via CSS theming or application resources
- No command-line tools needed for typical usage

**Finding icons:**
- Theme directory: `/usr/share/icons/Adwaita/`
- Scalable icons: `/usr/share/icons/Adwaita/scalable/`
- Actions, places, devices, and status categories follow standard FDO specifications
