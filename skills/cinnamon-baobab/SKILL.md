# baobab Skill

This skill provides functionality for `baobab`, a graphical disk usage analyzer for GNOME desktops.

**Overview:**
- `baobab` is a graphical tool for analyzing disk usage on Linux systems
- Provides a visual representation of directory sizes and disk space usage
- Part of the GNOME desktop environment
- Helps users identify large files and directories consuming disk space

**Commands:**
- `baobab` - Launch the Baobab disk usage analyzer GUI
- `baobab <path>` - Open Baobab with a specific directory path

**Usage:**
- Launch from application menu or terminal: `baobab`
- Scans the file system and displays directory sizes in a tree view
- Shows pie chart and treemap visualizations of disk usage
- Can scan local drives, network drives, and remote locations
- Right-click on directories to open in file manager or delete

**Package purpose:**
- Provides a user-friendly GUI for disk space analysis
- Part of the GNOME desktop utilities suite
- Integrated with Cinnamon desktop environment
