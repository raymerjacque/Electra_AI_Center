# caribou Skill

This skill provides functionality for `caribou`, an on-screen keyboard for Linux desktops.

**Overview:**
- `caribou` is an on-screen keyboard for Linux desktops
- Provides virtual keyboard input for users who cannot use a physical keyboard
- Part of the `caribou` package on Debian/Ubuntu systems
- Integrated with GNOME accessibility features

**Usage:**
- Launch from application menu: `caribou`
- Provides virtual keyboard for text input
- Can be configured through system accessibility settings
- Works with GNOME Shell and other desktop environments

**Package purpose:**
- Provides on-screen keyboard functionality for accessibility
- Essential for users with motor impairments or touchscreen devices
