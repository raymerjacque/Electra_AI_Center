# bulky Skill

This skill provides functionality for `bulky`, a graphical feed reader for the GNOME desktop.

**Overview:**
- `bulky` is a graphical RSS/Atom feed reader for the GNOME desktop
- Provides a clean interface for managing and reading web feeds
- Part of the `bulky` package on Debian/Ubuntu systems
- Integrated with the GNOME desktop environment

**Usage:**
- Launch from application menu: `bulky`
- Subscribe to feeds via URL or OPML import
- Supports keyboard shortcuts and mouse operations
- Integrated with notification area for new feed items

**Package purpose:**
- Provides a dedicated RSS/Atom feed reader for GNOME desktops
- Alternative to browser-based feed readers
- Part of the GNOME desktop utilities suite
