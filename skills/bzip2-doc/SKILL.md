# bzip2-doc Skill

This skill provides information about `bzip2-doc`, which contains the documentation and man pages for the bzip2 compression program.

**Overview:**
- `bzip2-doc` contains the manual pages and documentation for the bzip2 compression utility
- Provides reference material for using bzip2's command-line options and understanding the algorithm
- Part of the `bzip2` package suite on Debian/Ubuntu systems
- Architecture-independent documentation

**Usage:**
- View manual: `man bzip2` or `man bzip2recover`
- Documentation covers: compression options, decompression, file recovery, and environment variables
- Part of the standard bzip2 installation on Debian/Ubuntu systems

**Package purpose:**
- Provides documentation and man pages for the bzip2 compression utilities
- Essential for learning and referencing bzip2 command-line options
