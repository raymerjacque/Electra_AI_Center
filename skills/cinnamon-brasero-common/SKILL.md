# brasero-common Skill

This skill provides information about `brasero-common`, which contains common files for the Brasero CD/DVD burning application.

**Overview:**
- `brasero-common` provides the shared data and configuration for Brasero, the CD/DVD burning application for GNOME desktop
- Part of the standard GNOME desktop setup on Debian/Ubuntu/MakuluLinux systems
- Contains themes, icons, and configuration shared between the GUI and command-line components

**Usage:**
- Brasero is the default CD/DVD burning application for GNOME/Cinnamon desktops
- Can burn data discs, audio CDs, and video DVDs
- Integrated with the desktop environment for easy access
- Command-line interface available via `brasero` command

**Package purpose:**
- Provides common files needed by the Brasero application
- Architecture-independent resources and configuration
- Part of the GNOME desktop multimedia suite
