# bind9-libs Skill

This skill provides information about `bind9-libs`, the core shared libraries for the ISC BIND9 DNS server.

**Overview:**
- `bind9-libs` contains the essential shared libraries used by the BIND9 DNS server
- These libraries provide the DNS protocol implementation, caching, and resolution functions
- Part of the BIND9 package on Debian/Ubuntu systems (multi-arch: :amd64)
- Required by the `bind9-dnsutils` and `bind9-host` utilities

**Package purpose:**
- Provides the library foundation for BIND9 DNS operations
- Works with the bind9-dnsutils utilities for DNS queries and diagnostics
- Architecture-specific (:amd64) library files
- Essential for any BIND9 DNS server or client operations on amd64 systems
