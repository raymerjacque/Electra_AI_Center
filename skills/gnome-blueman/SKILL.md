# blueman Skill

This skill provides functionality for `blueman`, a graphical Bluetooth manager for the GNOME desktop environment.

**Overview:**
- `blueman` provides a complete Bluetooth management interface for the desktop
- Handles device pairing, connection, and management via a graphical interface
- Part of the `blueman` package on Debian/Ubuntu systems
- Integrates with the desktop environment's notification area

**Usage:**
- Launch from application menu: `blueman-manager`
- Or system tray icon for quick access
- Provides interface for:
  - Pairing new Bluetooth devices
  - Managing connected devices
  - Setting up serial and networking profiles
  - Viewing device information and properties

**Package purpose:**
- Graphical Bluetooth management for desktop environments
- User-friendly interface for Bluetooth configuration and device management
- Works with BlueZ, the official Linux Bluetooth protocol stack
